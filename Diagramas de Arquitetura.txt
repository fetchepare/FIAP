RESTRIÇÕES ADICIONAIS IMPLEMENTADAS
Diagrama de Restrições
┌─────────────────────────────────────────────────────────────────────────────────┐
│                    RESTRIÇÕES ADICIONAIS IMPLEMENTADAS                          │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  RESTRIÇÃO 1: DISTÂNCIA MÁXIMA POR VEÍCULO                              │    │
│  │                                                                          │    │
│  │  ┌─────────────────────────────────────────────────────────────────┐    │    │
│  │  │  distancia_max_por_veiculo = 800                                │    │    │
│  │  │                                                                 │    │    │
│  │  │  Para cada veículo:                                             │    │    │
│  │  │    distancia_total_veiculo = soma(segmentos)                    │    │    │
│  │  │    if distancia_total_veiculo > 800:                            │    │    │
│  │  │        penalidade += 5000 * (distancia - 800)                   │    │    │
│  │  └─────────────────────────────────────────────────────────────────┘    │    │
│  │                                                                          │    │
│  │  🎯 OBJETIVO: Evitar rotas excessivamente longas que atrasam            │    │
│  │              atendimentos e aumentam custos operacionais.               │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                  │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  RESTRIÇÃO 2: PRAZO MÁXIMO DE TRANSPORTE                                │    │
│  │                                                                          │    │
│  │  ┌─────────────────────────────────────────────────────────────────┐    │    │
│  │  │  Para cada paciente com 'prazo_max' definido:                   │    │    │
│  │  │    tempo_acumulado = distância desde depósito até o paciente    │    │    │
│  │  │    if tempo_acumulado > prazo_max:                              │    │    │
│  │  │        penalidade += 8000                                       │    │    │
│  │  └─────────────────────────────────────────────────────────────────┘    │    │
│  │                                                                          │    │
│  │  🎯 OBJETIVO: Garantir que medicamentos urgentes ou atendimentos        │    │
│  │              críticos sejam realizados dentro do tempo limite.          │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                  │
│  📊 IMPACTO NO FITNESS:                                                          │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  Fitness = Distância Total + Penalidades                                │    │
│  │                                                                          │    │
│  │  Sem restrições: rota mais curta, mas pode violar limites               │    │
│  │  Com restrições: algoritmo prioriza soluções que respeitam limites     │    │
│  │                  mesmo que a distância seja ligeiramente maior         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────────────────┘
